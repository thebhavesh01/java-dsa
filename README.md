## 🚀 Running the Programs

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project:

```bash
cd java-dsa
```

Compile a Java program:

```bash
javac java_fundamentals/question1.java
```

Run it:

```bash
java java_fundamentals.question1
```
